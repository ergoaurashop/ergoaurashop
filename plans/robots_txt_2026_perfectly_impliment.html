WHAT IS CRAWL BUDGET?

The number of pages Google will crawl on your site per day. Wasted crawl = valuable pages not indexed. For sites under 1,000 pages, crawl budget is rarely an issue — but for large sites it's critical.

Pages that waste crawl budget — always block
  • URL parameters that create duplicate content (?ref=, ?utm_, ?session=)
  • Paginated pages beyond page 3 (use rel="next" instead)
  • Tag and archive pages with thin content
  • Internal search result pages
  • Print-friendly page versions
  • Login/account/profile pages
  • Thank-you and confirmation pages
  • Staging or dev subfolders left exposed
Always allow (critical 2026 rule)
  • All .css files — Google renders pages to evaluate layout quality
  • All .js files — blocking JS hides content from Google's renderer
  • All font files — affects Core Web Vitals CLS score
  • Image CDN paths used in structured data
Most damaging robots.txt mistakes in 2026
MISTAKE #1 — BLOCKING CSS/JS

Disallowing *.css or *.js prevents Google from rendering your pages. Google sees a broken layout and may downgrade rankings. This is the single most common fatal error.

MISTAKE #2 — DISALLOW: / ACCIDENT

A single Disallow: / under User-agent: * blocks your entire site from all bots. Usually introduced during staging and never removed. Check logs immediately if traffic drops to zero.

MISTAKE #3 — USING robots.txt FOR PRIVATE PAGES

robots.txt is public. Anyone can read it. Never list URLs here you want to hide — use authentication or noindex meta tags instead. Listing /secret-deals/ in robots.txt just advertises it.

MISTAKE #4 — TRAILING SLASH MISMATCH

Disallow: /admin blocks /admin but NOT /admin/. Always use trailing slashes for directories: Disallow: /admin/

MISTAKE #5 — BLOCKING noindexed PAGES

Paradox: if you block a page in robots.txt, Google can't crawl it to read the noindex tag — it may still appear in search as a URL-only result. Block OR noindex, not both.

MISTAKE #6 — WRONG SITEMAP PROTOCOL

Always use absolute, fully-qualified HTTPS URLs for Sitemap: directives. Sitemap: /sitemap.xml is wrong. Use Sitemap: https://yourdomain.com/sitemap.xml

MYTH — Crawl-delay works for Google

Google officially ignores Crawl-delay. Use Google Search Console's crawl rate settings instead. Crawl-delay is respected by Bing, Yandex, and most other bots.

Pre-launch robots.txt audit — 2026
  • File is served at exactly https://yourdomain.com/robots.txt
  • File returns HTTP 200 (not 301/404/500)
  • File is plain text, UTF-8, no BOM
  • Under 500 KB in size (ideally under 50 KB)
  • No Disallow: / under User-agent: * unless intentional
  • CSS and JS files are allowed (not blocked)
  • At least one Sitemap: directive with HTTPS URL
  • Staging/dev paths are disallowed
  • Admin, login, checkout pages are disallowed
  • AI training bots are explicitly blocked
  • Parameter-based duplicate URLs are disallowed
  • Tested in Google Search Console robots.txt tester
  • Verified in Bing Webmaster Tools
  • No sensitive URLs exposed in file (privacy check)
  • Reviewed after every major site restructure
