## Content Per Product (Template Structure)

Each `.md` file will contain all content needed for that product's page:

### 1. Title

- 60-80 chars
- 4-part formula: Result → Product name → Key spec/material → Who it's for
- No brand names, no ALL CAPS, no fake claims

### 2. Tagline / Subtitle

- 100-120 chars
- Emotion word + life after + time saved
- Sentence case, no full stop

### 3. Benefits Strip (4 icons)

- Short label + icon concept for each

### 4. 5 Bullet Benefits (15-20 words each)

1. Core benefit — #1 reason to buy
2. Material/safety — builds trust
3. Ease of use — no learning curve
4. Saves money/time — ROI
5. Guarantee — return/warranty

### 5. Pain vs Solution (2-3 items each side)

- "Without it" pains (red)
- "With it" solutions (green)

### 6. Description Body (4 subsections)

1. **The Problem** (empathy hook, 40-60 words)
2. **The Solution** (product reveal, plain language)
3. **What's in the Box + Specs** (table format)
4. **Who This Is Perfect For** (3-4 customer types + gifting angle)

### 7. FAQ (3 questions, 20-40 words each)

- Kill last 3 objections before cart abandonment

### 8. Sample Reviews (2-3 reviews)

- Indian names + city names
- 4.5+ star ratings
- Verified purchase tags

### 9. Trust Bar Items

- 100% original, Free delivery above ₹299, 7-day easy return, Secure checkout

## Quality Checklist (per product)

- [ ] Title follows 4-part formula, 60-80 chars
- [ ] Tagline is 100-120 chars, emotional, no full stop
- [ ] 5 bullets follow structure (benefit + proof each, 15-20 words)
- [ ] Problem hook is 40-60 words, names exact pain
- [ ] Solution reveal explains how it works in plain language
- [ ] What's in the box has clean table format
- [ ] "Who this is for" lists 3-4 specific customer types
- [ ] FAQ has 3 questions, 20-40 words each
- [ ] Pain vs Solution has 2-3 items each side
- [ ] Reviews use Indian names + cities, 4.5-5.0 stars
- [ ] No brand names, manufacturer names, or contact info
- [ ] Uses "saves ₹X" language where applicable
- [ ] Discount % between 30-55 (per suggested table)
- [ ] Total word count per product ~500-700 words
